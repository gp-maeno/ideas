# Garden Simulator - 実装計画

## 概要・目的

撮影した写真（または庭のカメラ映像）の上に3Dの植物・花壇モデルを配置し、ガーデニングのイメージをシミュレーションできるWebアプリ。iOS/Android両対応。

## 技術スタック

| 技術 | 用途 | 選定理由 |
|---|---|---|
| Three.js | 3Dモデル描画・シーン管理 | カメラ映像上に3Dオブジェクトを重ねる擬似AR |
| CSS変数 | テーマ管理 | Three.jsフルスクリーン系はTailwind不要 |
| Vanilla JS (ES2020+) | UI制御 | 軽量、依存なし |

**Tailwind/Alpine.js不使用の理由:** 画面の大部分がカメラ映像+3Dオーバーレイで構成されるため、CSS変数ベースのカスタムCSSが適切。

## 機能一覧

### コア機能

1. **写真入力** - カメラ撮影 or 画像アップロード
2. **タップ配置** - 写真上でタップした位置にそのまま植物を配置（ピンチで拡縮）
3. **プリセット提案** - 画面中央付近に花壇パターンを一括配置、個別に調整可能
   - 和風（松・苔・石）
   - 洋風（バラ・レンガ花壇）
   - ナチュラル（野草・グラス系）
   - カラフル（季節の花ミックス）
4. **個別配置** - 植物を1つずつ選んでタップ配置
5. **操作** - 配置した植物の移動・回転・拡縮・削除

### 植物の表現

3Dモデル（GLTF）のロードは重く管理も大変なため、**ビルボード方式**を採用:
- 植物のPNG画像をPlaneジオメトリに貼り付け
- 常にカメラに正面を向ける（ビルボード）
- 影をドロップシャドウ（楕円の半透明Plane）で表現
- 軽量で種類の追加も容易

### 植物データ（初期セット: 12種程度）

| カテゴリ | 植物例 |
|---|---|
| 花 | バラ、チューリップ、ラベンダー、ひまわり |
| 低木 | ツツジ、アジサイ、ツゲ |
| 高木 | 松、モミジ |
| グラウンドカバー | 芝生、苔、クローバー |
| 構造物 | レンガ花壇枠、石、灯籠 |

植物画像はSVGまたはCSS/Canvasで動的生成する（外部アセット不要で自己完結）。

## 実装フェーズ

### Phase 1: 基盤（カメラ + Three.jsオーバーレイ）
- ディレクトリ構成・HTMLスケルトン作成
- カメラ起動 / 画像アップロード機能
- Three.jsシーン初期化（カメラ映像をバックグラウンドに）
- タップした位置にテスト用オブジェクトを配置

### Phase 2: 植物システム
- 植物データ定義（名前・サイズ・画像）
- Canvas APIで植物画像を動的生成
- ビルボード表示 + ドロップシャドウ
- 植物パレットUI

### Phase 3: プリセット＆操作
- プリセットパターン定義（和風・洋風・ナチュラル・カラフル）
- プリセット選択で一括配置
- 配置済みオブジェクトの選択・移動・拡縮・削除
- 操作UI（選択時のハンドル表示）

### Phase 4: 仕上げ
- レスポンシブ調整（スマホ最優先）
- ローディング表示
- meta.json作成
- 動作確認・デプロイ

## 懸念点と対策

| 懸念 | 対策 |
|---|---|
| 植物画像のアセット管理 | Canvas APIで動的生成。外部画像不要 |
| 3D配置の奥行き感 | 画面下部ほど手前（大きく）、上部ほど奥（小さく）の簡易パース |
| スマホでの操作性 | タッチジェスチャー対応、大きめのタップターゲット |
| パフォーマンス | ビルボード方式で軽量化、植物数の上限設定（30個程度） |
| カメラ権限が拒否された場合 | 画像アップロードにフォールバック |
