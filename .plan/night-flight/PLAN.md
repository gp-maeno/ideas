# Tokyo Night Flight - 実装計画
 
## Context
 
Ideas Labに新規プロジェクト「Tokyo Night Flight」を追加する。国交省のPLATEAU（3D都市モデル）を活用し、夜の東京上空をシネマティックに飛行する体験を作る。自動飛行をベースに手動操作にも切り替え可能。BGMはWeb Audio APIでプロシージャル生成。
 
## 技術スタック
 
| 要素 | 選定 | 理由 |
|------|------|------|
| 3D描画 | **CesiumJS** (CDN) | PLATEAU 3D TilesをCesium Ion経由で読み込み。タイルストリーミング・モバイル操作・カメラアニメーション内蔵 |
| データ | **Cesium Ion** (無料) | 日本の3Dビルデータ（PLATEAU由来）がホスト済み。自前ホスティング不要 |
| 夜景表現 | CesiumJS **CustomShader** + **PostProcessStage** | ビルに窓明かりシェーダー、ブルーム・ビネット等のポスト処理 |
| BGM | **Web Audio API** | OscillatorNode + フィルターでアンビエント音楽を軽量生成 |
| UI | CSS変数 + Vanilla JS | Tailwind不要（フルスクリーン3Dアプリ、stellaと同じ方針） |
 
## ファイル構成
 
```
night-flight/
├── index.html              ← HTML構造のみ（CesiumJS CDN読み込み）
├── meta.json               ← メタ情報
└── assets/
    ├── css/night-flight.css ← UI・ローディング画面のスタイル
    └── js/night-flight.js  ← メインロジック
```
 
## 実装フェーズ
 
### Phase 1: 基盤セットアップ
- `night-flight/` ディレクトリ・ファイル作成
- `index.html`: CesiumJS CDN読み込み、ローディング画面HTML
- `meta.json` 作成
- CesiumJS Viewerの初期化（東京中心にカメラ配置）
- Cesium Ion トークン設定、PLATEAU 3D Buildings読み込み確認
 
### Phase 2: 夜景シーン構築
- **黒背景**: 衛星画像なし、真っ暗な地球表面
- **CustomShader**: ビルに適用する夜景シェーダー
  - 壁面: 暗いグレー/ネイビー
  - 窓パターン: ワールド座標ベースのプロシージャルグリッド
  - 窓の発光: 暖色（黄〜オレンジ）でランダムにON/OFF
- **PostProcessStage**:
  - ブルーム（光のにじみ）
  - カラーコレクション（ブルーシフト、コントラスト強調）
  - ビネット（画面端の暗化、シネマティック感）
- **フォグ**: 水平線付近に霞み効果
- **星空**: シンプルなスカイボックスまたはパーティクル
 
### Phase 3: カメラ飛行システム
- **ウェイポイント定義** (経緯度・高度・heading・pitch):
  1. 東京湾アプローチ（高高度から降下）
  2. 東京タワー周辺 (35.6586, 139.7454)
  3. 渋谷エリア (35.6595, 139.7004)
  4. 新宿高層ビル群 (35.6938, 139.7034)
  5. 東京スカイツリー (35.7101, 139.8107)
  6. お台場・レインボーブリッジ (35.6365, 139.7635)
  7. 東京湾上昇→ループ
- **補間**: CesiumJSの`camera.flyTo`またはカスタムlerp（CatmullRom等）
- **速度制御**: UIスライダーまたはタップで速度変更
- **ループ再生**: 最後のウェイポイント→最初に滑らかに戻る
 
### Phase 4: 手動操作モード
- **切替ボタン**: AUTO / MANUAL トグル
- **手動操作**:
  - タッチドラッグ: カメラの向き変更
  - ピンチ: ズーム
  - ジャイロ（モバイル）: デバイスの傾きでカメラ向き制御（iOS許可フロー含む）
- **AUTO復帰**: 手動モード中にAUTOボタンで最寄りウェイポイントから再開
 
### Phase 5: Web Audio BGM
- **アンビエントパッド**: 低周波オシレーター（sine/triangle）+ ローパスフィルター
- **高域シマー**: 高周波オシレーター + ディレイで煌めき効果
- **風切り音**: ノイズジェネレーター + バンドパスフィルター（高度で変化）
- **インタラクション**: 高度に応じて音量・フィルター変化
- **ミュートボタン**: UIに常時表示
- **自動開始**: ユーザーの最初のタップ/クリック後に再生開始（ブラウザポリシー対応）
 
### Phase 6: UI・ローディング
- **ローディング画面**:
  - ダーク背景、プログレスバー
  - "Preparing for takeoff..." → "Ready" のメッセージ
  - CesiumJS + タイル読み込み完了後にフェードアウト
- **フライト中UI（ミニマル）**:
  - 現在地ラベル（ウェイポイント名を表示）
  - AUTO/MANUAL切替
  - 速度コントロール（+ / -）
  - ミュートボタン
  - `← Gallery` 戻りリンク
- **モバイル最適化**: タッチターゲット44px以上、下部にコントロール配置
 
## 参照ファイル（既存パターン）
 
- `stella/index.html` - HTML構造のテンプレート（Three.jsフルスクリーンアプリ）
- `stella/assets/js/stella.js` - ローディングパターン、状態管理、ジャイロ制御、iOS許可フロー
- `stella/assets/css/stella.css` - CSS変数によるダークテーマ、UIオーバーレイのスタイリング
- `stella/meta.json` - meta.jsonの書式
 
## パフォーマンス戦略
 
| 課題 | 対策 |
|------|------|
| CesiumJS ~3MB | ローディング画面でカバー。gzip圧縮で実質~1MB |
| 3D Tilesデータ量 | Cesium Ionのストリーミング（視野内のみ読み込み） |
| 初回レンダリング | カメラを高高度から開始（少ないタイルで初期表示） |
| モバイルGPU | pixelRatio上限2.0、LODは自動（CesiumJS管理） |
| Web Audio | 軽量（オシレーター数個のみ、音声ファイルなし） |
 
## Cesium Ion セットアップ
 
- 無料アカウントでアクセストークンを取得
- Japan 3D Buildings アセット（PLATEAU由来、Cesium Ion Asset Depot で利用可能）を参照
- トークンはJSにハードコード（ポートフォリオプロジェクトのため許容）
 
## 検証方法
 
1. ローカルで `python -m http.server` 等で `night-flight/index.html` を開く
2. ローディング画面が表示され、3Dシーンが読み込まれることを確認
3. 東京のビル群が夜景シェーダーで表示されることを確認
4. 自動飛行がウェイポイント間を滑らかに移動することを確認
5. AUTO/MANUAL切替が動作することを確認
6. Web Audio BGMが再生されることを確認（初回タップ後）
7. モバイルでタッチ操作・ジャイロが動作することを確認
8. `← Gallery` リンクで一覧に戻れることを確認
9. `_scripts/build-manifest.sh` でmanifest.jsonに含まれることを確認
