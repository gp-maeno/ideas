# Tokyo Night Flight - 実装計画

## Context

Ideas Labに新規プロジェクト「Tokyo Night Flight」を追加する。国交省のPLATEAU（3D都市モデル）を活用し、夜の東京上空をシネマティックに飛行する体験を作る。自動飛行をベースに手動操作にも切り替え可能。BGMはWeb Audio APIでプロシージャル生成。

## 技術スタック

| 要素 | 選定 | 理由 |
|------|------|------|
| 3D描画 | **CesiumJS** (CDN, バージョン固定) | PLATEAU 3D TilesをCesium Ion経由で読み込み。タイルストリーミング・モバイル操作・カメラアニメーション内蔵 |
| データ | **Cesium Ion** (無料) | 日本の3Dビルデータ（PLATEAU由来）がホスト済み。自前ホスティング不要 |
| 夜景表現 | CesiumJS **CustomShader** + **PostProcessStage** | ビルに窓明かりシェーダー、ブルーム・ビネット等のポスト処理 |
| BGM | **Web Audio API** | OscillatorNode + フィルターでアンビエント音楽を軽量生成 |
| UI | CSS変数 + Vanilla JS | Tailwind不要（フルスクリーン3Dアプリ、stellaと同じ方針） |

> **CDNバージョン固定**: CesiumJS CDNは特定バージョンを指定する（例: `cesium@1.125`）。PostProcessStage等のAPIはバージョン間で変更があるため、未固定だと動作しなくなるリスクがある。

## ファイル構成

```
night-flight/
├── index.html              ← HTML構造のみ（CesiumJS CDN読み込み）
├── meta.json               ← メタ情報
└── assets/
    ├── css/night-flight.css ← UI・ローディング画面のスタイル
    └── js/night-flight.js  ← メインロジック（800行超過時はaudio.js等に分割）
```

## 実装フェーズ

### Phase 1: 基盤セットアップ
- `night-flight/` ディレクトリ・ファイル作成
- `index.html`: CesiumJS CDN読み込み（**バージョン固定**）、ローディング画面HTML
- `meta.json` 作成
- **Cesium Ion Asset IDの確認**: Asset DepotでJapan 3D BuildingsのAsset IDを特定し、アクセス可能か検証する。アクセスできない場合はPLATEAUの3D Tilesを直接参照する代替案に切り替え
- CesiumJS Viewerの初期化（東京中心にカメラ配置）
- Cesium Ion トークン設定（リファラー制限・読み取り専用・対象アセット限定）、PLATEAU 3D Buildings読み込み確認

### Phase 2: 夜景シーン構築
- **黒背景**: 衛星画像なし、真っ暗な地球表面
- **CustomShader**: ビルに適用する夜景シェーダー（ライティングモデル: `UNLIT`）
  - 壁面: 暗いグレー/ネイビー
  - 窓パターン: **モデル座標（positionMC）ベース**のプロシージャルグリッド（※ECEF座標は直接アクセス不可のため）
  - 窓の発光: 暖色（黄〜オレンジ）でランダムにON/OFF
  - **フォールバック**: CustomShaderが期待通り動作しない場合、単色発光（暖色emissive）+ ブルームのみで夜景を表現する簡易版に切り替え
- **PostProcessStage**:
  - ブルーム（光のにじみ）
  - カラーコレクション（ブルーシフト、コントラスト強調）
  - ビネット（画面端の暗化、シネマティック感）
- **フォグ**: 水平線付近に霞み効果
- **星空**: シンプルなスカイボックスまたはパーティクル

> **リスク注記**: CustomShaderでのプロシージャル窓パターンは技術的に最もリスクが高い。CesiumJS CustomShaderではECEF（ワールド）座標に直接アクセスできず、利用可能なのはモデル座標（MC）と目線座標（EC）のみ。モデル座標は各建物ごとのローカル座標だが、夜景としては建物ごとに異なる窓パターンになり自然に見える。Phase 2の早い段階でプロトタイプ検証し、問題があればフォールバック案に切り替える。

### Phase 3: カメラ飛行システム
- **ウェイポイント定義** (経緯度・高度・heading・pitch):
  1. 東京湾アプローチ（高高度から降下）
  2. 東京タワー周辺 (35.6586, 139.7454)
  3. 渋谷エリア (35.6595, 139.7004)
  4. 新宿高層ビル群 (35.6938, 139.7034)
  5. 東京スカイツリー (35.7101, 139.8107)
  6. お台場・レインボーブリッジ (35.6365, 139.7635)
  7. 東京湾上昇→ループ
- **補間**: `Cesium.CatmullRomSpline`（CesiumJS組み込み）の利用を優先検討。不足があればカスタム実装に切り替え
- **速度制御**: UIスライダーまたはタップで速度変更
- **ループ再生**: 最後のウェイポイント→最初に滑らかに戻る

### Phase 4: 手動操作モード
- **切替ボタン**: AUTO / MANUAL トグル
- **手動操作**:
  - タッチドラッグ: カメラの向き変更
  - ピンチ: ズーム
- **AUTO復帰**: 手動モード中にAUTOボタンで最寄りウェイポイントから再開

> **スコープ注記**: ジャイロ操作（デバイスの傾きによるカメラ制御）はnice-to-haveとする。CesiumJSの標準カメラコントローラーとの共存が複雑なため、Phase 1〜6の完成後に余裕があれば追加する。

### Phase 5: Web Audio BGM
- **アンビエントパッド**: 低周波オシレーター（sine/triangle）+ ローパスフィルター
- **高域シマー**: 高周波オシレーター + ディレイで煌めき効果
- **インタラクション**: 高度に応じて音量・フィルター変化
- **ミュートボタン**: UIに常時表示
- **自動開始**: ユーザーの最初のタップ/クリック後に再生開始（ブラウザポリシー対応）

> **スコープ注記**: 風切り音（ノイズジェネレーター + バンドパスフィルター）はnice-to-haveとする。パラメータチューニングに時間がかかる可能性があるため、まずアンビエントパッド + シマーでBGMを完成させ、余裕があれば追加する。

### Phase 6: UI・ローディング
- **ローディング画面**:
  - ダーク背景、プログレスバー
  - "Preparing for takeoff..." → "Ready" のメッセージ
  - **読み込み完了判定**: `tileset.allTilesLoaded`イベントを基準とするが、3D Tilesはストリーミング読み込みのため明確な「完了」がない。高高度スタートで初期タイルが少ないことを利用し、タイムアウト（5秒）後にフェードインする方式を併用
  - Cesium Ionデータ読み込み失敗時のエラーメッセージ表示（無料枠超過対策）
- **フライト中UI（ミニマル）**:
  - 現在地ラベル（ウェイポイント名を表示）
  - AUTO/MANUAL切替
  - 速度コントロール（+ / -）
  - ミュートボタン
  - `← Gallery` 戻りリンク
- **モバイル最適化**: タッチターゲット44px以上、下部にコントロール配置

## パフォーマンス戦略

| 課題 | 対策 |
|------|------|
| CesiumJS ~3MB | ローディング画面でカバー。gzip圧縮で実質~1MB。※「初回ロード3秒以内」目標はCesiumJS読み込みのため超過を許容 |
| 3D Tilesデータ量 | Cesium Ionのストリーミング（視野内のみ読み込み） |
| 初回レンダリング | カメラを高高度から開始（少ないタイルで初期表示） |
| モバイルGPU | pixelRatio上限2.0、LODは自動（CesiumJS管理） |
| Web Audio | 軽量（オシレーター数個のみ、音声ファイルなし） |
| JSファイルサイズ | 800行超過時にモジュール分割（audio.js等）を検討 |

## Cesium Ion セットアップ

- 無料アカウントでアクセストークンを取得
- **Phase 1冒頭でAsset IDを確認**: Japan 3D Buildings アセット（PLATEAU由来）のAsset IDをAsset Depotで特定。アクセスできない場合はPLATEAUの3D Tilesを直接参照する代替案に切り替え
- トークンはJSにハードコード（公開リポジトリのため以下の対策を実施）:
  - **リファラー制限**: Cesium Ionのトークン設定で `gp-maeno.github.io` のみ許可
  - **トークンスコープ最小化**: 読み取り専用、対象アセットのみに制限
  - **無料枠の監視**: 月間500,000タイルリクエスト上限。アクセス数が上限に近づいていないか定期的に確認
  - **枠超過時のフォールバック**: ローディング画面にエラーメッセージを表示

## 検証方法

1. ローカルで `python -m http.server` 等で `night-flight/index.html` を開く
2. ローディング画面が表示され、3Dシーンが読み込まれることを確認
3. 東京のビル群が夜景シェーダーで表示されることを確認
4. 自動飛行がウェイポイント間を滑らかに移動することを確認
5. AUTO/MANUAL切替が動作することを確認
6. Web Audio BGMが再生されることを確認（初回タップ後）
7. モバイルでタッチ操作が動作することを確認
8. `← Gallery` リンクで一覧に戻れることを確認
9. `_scripts/build-manifest.sh` でmanifest.jsonに含まれることを確認
10. Cesium Ion読み込み失敗時にエラーメッセージが表示されることを確認
