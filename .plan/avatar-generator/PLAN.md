# Avatar Generator - 実装計画

## 概要

Claude Code CLIにログイン時に表示されるピクセルアートキャラクターをカスタマイズできるアバタージェネレータ。
パーツの組み合わせでオリジナルのClaudeアバターを作成し、PNG画像としてダウンロードできる。

## 技術スタック

| 技術 | 用途 | 選定理由 |
|------|------|----------|
| SVG | キャラクター描画 | ベクター形式で拡大縮小に強い。パーツの差し替えがDOM操作で容易 |
| Canvas API | PNG出力 | SVGをCanvasに描画してPNG変換 |
| CSS変数 + Vanilla JS | UI・スタイリング | カスタムCSSが主体のためTailwind不要。カラーピッカー等のUIはネイティブ要素で実現 |

**Tailwind CSSを使わない理由:** フルスクリーンのジェネレータUIで、ピクセルアート風のカスタムデザインが主体。TailwindのユーティリティクラスよりもCSS変数ベースの方が制御しやすい。

## カスタマイズ要素

### 基本（必須）
| カテゴリ | 内容 |
|----------|------|
| 背景色 | カラーピッカーで自由選択 + プリセット |
| キャラクター色 | 体・頭の色（カラーピッカー + プリセット） |
| 目の色 | 目の色を変更 |
| 被り物 | なし / 王冠 / パーティーハット / ヘッドホン / 猫耳 / ニット帽 / ハッカーフード |

### 追加
| カテゴリ | 内容 |
|----------|------|
| 表情 | デフォルト / 笑顔（^ ^） / 驚き（○○） / ウインク / ハート目 / キラキラ目 |
| アクセサリー | なし / メガネ / サングラス / マスク / ヒゲ / ほっぺ（赤み） |
| 持ち物 | なし / コーヒーカップ / ノートPC / 剣 / 旗 / ハート |

## ベースキャラクターの仕様

スクリーンショットから読み取れるピクセルアートの構成:
- 頭部: 横長の長方形（角丸なし、ピクセルアート風）
- 目: 2つの小さな黒い正方形
- 耳（突起）: 頭部の上に2つ
- 足: 下部に3本の短い線

→ SVGで `<rect>` を組み合わせてピクセルアート風に再現する

## 出力

- **PNG**: SVGをCanvasに描画 → `toDataURL()` → ダウンロード
- 出力サイズ: 512x512px（ピクセルアートなのでシャープに）
- ファイル名: `avatar.png`

## 実装フェーズ

### Phase 1: 基盤構築
1. ディレクトリ構造・HTML・CSS・JS ファイルの作成
2. ベースキャラクターのSVG定義（スクリーンショットを忠実に再現）
3. プレビュー領域の表示

### Phase 2: カスタマイズ機能
4. カテゴリタブUI の実装
5. 背景色・キャラクター色・目の色のカラーピッカー実装
6. 被り物パーツのSVG定義と切り替え
7. 表情バリエーションの実装
8. アクセサリーパーツの実装
9. 持ち物パーツの実装

### Phase 3: 出力・仕上げ
10. ランダム生成機能
11. PNG ダウンロード機能（Canvas経由）
12. レスポンシブ対応・モバイル最適化
13. meta.json 作成

## 懸念点と対策

| 懸念 | 対策 |
|------|------|
| ピクセルアートのSVG再現が原画と異なる可能性 | スクリーンショットを精密に分析し、グリッドベースで配置。Phase 1完了時にユーザー確認 |
| パーツ同士の重なり・位置合わせ | SVGの `<g>` グループでレイヤー管理。z-indexに相当する描画順序を制御 |
| PNG出力時の品質 | Canvasの `imageSmoothingEnabled = false` でピクセルをシャープに保つ |
| パーツ数が増えると管理が煩雑に | パーツをJSオブジェクトで定義し、データドリブンでSVGを生成 |
