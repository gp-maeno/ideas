# Tokyo Night Flight

夜の東京上空をシネマティックに飛行する体験。国交省PLATEAUの3D都市モデルを活用し、窓明かりが灯るビル群の上空を自動飛行する。

## 特徴

### 夜景表現
- **ビルタイプ別の窓明かり**: CustomShaderでビルごとにオフィス（白・青白）、住居（暖色）、商業（多彩）の3タイプを自動分類
- **リアルな消灯パターン**: ビル単位のハッシュで明るいビル・暗いビルの差を表現。消灯率55〜85%
- **シルエット表現**: エッジフレネルでビルの輪郭を微かに浮かび上がらせる
- **ポストプロセス（PCのみ）**: ブルーム（光のにじみ）、ビネット（画面端の暗化）、カラーコレクション（ブルーシフト）
- **黒背景**: 衛星画像・テレイン・大気を無効化し、漆黒の夜空にビルの明かりだけが浮かぶシーン

### 自動飛行
- 東京の主要ランドマーク7箇所を巡回するウェイポイント飛行
  1. 東京湾アプローチ（高高度から降下）
  2. 東京タワー周辺
  3. 渋谷エリア
  4. 新宿高層ビル群
  5. 東京スカイツリー
  6. お台場・レインボーブリッジ
  7. 東京湾上昇 → ループ
- イージング付き滑らかな補間、角度の最短経路回転

### 手動操作
- AUTO / MANUAL モードをワンタップで切替
- MANUALモードではタッチドラッグ・ピンチでカメラを自由に操作
- AUTOに戻すと最寄りウェイポイントから飛行再開

### BGM
- Web Audio APIによるプロシージャル生成（音声ファイル不要）
- 低周波アンビエントパッド + 高域シマー（ディレイ付き煌めき効果）
- 高度に応じて音量・フィルターが動的に変化
- ユーザーの最初のタップ後に自動再生開始（ブラウザポリシー対応）

## 技術スタック

| 技術 | 用途 |
|---|---|
| CesiumJS 1.137 (CDN) | 3Dグローブ・タイルストリーミング |
| Cesium Ion | PLATEAU 3D Buildings のホスティング |
| CustomShader (GLSL) | 夜景ビルシェーダー（ビルタイプ別窓色・エッジフレネル） |
| PostProcessStage | ブルーム・ビネット・カラーコレクション（PCのみ） |
| Web Audio API | プロシージャルBGM生成 |
| CSS変数 + Vanilla JS | UI（Tailwind不要） |

## データソース

- **3D建物データ**: [PLATEAU](https://www.mlit.go.jp/plateau/) (国土交通省) - 3D都市モデル
- **配信**: [Cesium Ion](https://ion.cesium.com/) Asset Depot 経由
- **テレイン**: 無効（夜景では黒背景のため不要、パフォーマンス優先）

## 操作方法

### スマートフォン
1. ページを開くとローディング画面が表示される
2. 読み込み完了後、自動飛行が開始
3. 画面をタップするとBGMが再生開始
4. 下部のボタンで操作：
   - **AUTO/MANUAL**: 飛行モード切替
   - **-/+**: 飛行速度変更（0.25x〜4.0x）
   - **BGM/OFF**: ミュート切替

### PC
- 自動飛行を観賞
- MANUALモードでマウスドラッグ・ホイールでカメラ操作

## Cesium Ion セットアップ

このプロジェクトを動作させるには Cesium Ion のアクセストークンが必要:

1. [Cesium Ion](https://ion.cesium.com/) で無料アカウントを作成
2. Asset Depot で「Japan 3D Buildings」を自分のアカウントに追加
3. Access Tokens ページでトークンを取得
4. `assets/js/night-flight.js` の `CESIUM_ION_TOKEN` と `JAPAN_BUILDINGS_ASSET_ID` を設定

### セキュリティ対策
- トークンにリファラー制限を設定（`gp-maeno.github.io` のみ許可）
- トークンスコープを読み取り専用・対象アセット限定に制限

## パフォーマンス最適化

スマホ・PC両方で快適に動作するよう、デバイス別のチューニングを実施:

- **スマホ**: 解像度65%、ポストプロセス全無効、3D Tiles LOD粗め（SSE=32）、メモリ64MB制限
- **PC**: 解像度min(dpr,1.5)、ブルーム+ビネット+カラーコレクション有効、LOD中程度（SSE=12）
- **共通**: テレイン無効、スカイボックス・大気無効、フォグで遠方タイルを隠す、requestRenderMode
